# Interface sample images

These four photographs were supplied in `Detect-html.zip` as the interface
design reference on 22 October 2026. They are available for interactive
inference only; they are not a new labelled benchmark or reviewed OCR truth.
The filenames describe the photographs, not labels used by the recognition
pipeline. All displayed predictions and confidence values come from inference.

Existing training, validation and test images remain under `data/images/`.
